# HayPaComer documentation

The documentation of **HayPaComer**, the smart fridge that answers "what can I cook right now with what is actually at home?". Work happens here and goes straight to `main`; the history up to version 1.1.0 comes from the monorepo [Juansit-0/HayPaComer](https://github.com/Juansit-0/HayPaComer), with each commit kept under its original author.

## What is here

- `docs/`: architecture, data model, REST API, event protocol, GoF patterns, responsible AI, firmware, hardware, demo script, production runbook, ADRs, and the original proposal;
- `brand/`: naming, positioning, voice, identity, and design tokens;
- `PLAN.md` and `CHANGELOG.md`: the master plan and the release history.
